# BlazorDeCompressor

This tool can compress and decompress files using Gzip, Brotli, Deflate, Zlib, and Zstandard right inside the browser without transmitting files over the network.
Learn more about this tool at https://swimburger.net/blog/dotnet/introducing-online-gzip-decompressor.

Use the format-specific versions at [gzip.swimburger.net](https://gzip.swimburger.net), [brotli.swimburger.net](https://brotli.swimburger.net), [deflate.swimburger.net](https://deflate.swimburger.net), [zlib.swimburger.net](https://zlib.swimburger.net), and [zstd.swimburger.net](https://zstd.swimburger.net).

## Requirements

- [.NET 11 SDK](https://dotnet.microsoft.com/download/dotnet/11.0)

## Run locally

```bash
dotnet run
```
